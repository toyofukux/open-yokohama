# 都市比較・公共的論点・海外事例の拡充案

更新: 2026-09-06。状態: 開発候補の整理です。統計の収録、比較結果、政策効果の検証は未実施です。
既存の人口・暮らし・財政の拡充に、国内比較、注目論点、海外事例の3つの視点を加えます。

## 国内都市比較

「競合都市」は総合順位を固定せず、人口、雇用、企業立地、子育て、港湾など、問いごとに比較する都市を選びます。

| 比較の視点 | 対象候補 | 最初に確かめる問い |
|---|---|---|
| 東京との関係 | 東京都全体、東京都区部、必要に応じて個別区市 | 人口移動、通勤、仕事、本社、子育て支援、住宅費はどう違うか |
| 首都圏の生活・就業 | 川崎、さいたま、千葉 | どの年代が転入し、どこで働き、どの程度の住居費を負担するか |
| 大都市の経済・財政 | 大阪、名古屋、福岡 | 雇用、事業所、所得、税収、若年人口、住宅費はどう推移したか |
| 港湾・都市再生 | 神戸、必要に応じて国内の他の港湾都市 | 港湾と市内雇用、都心再開発、観光、住宅供給はどう結び付くか |

初回は横浜、東京都区部、川崎、福岡、神戸を比較候補とし、同じ定義で取れる人口・年齢・移動・就業から始める案です。
東京都全体の人口・経済も別系列として用意し、区部と混同しません。大阪、名古屋、さいたま、千葉は問いに合わせて広げます。

一次資料の入口として、横浜市が公開する[大都市比較統計年表](https://www.city.yokohama.lg.jp/city-info/yokohamashi/tokei-chosa/portal/nenpyo/daitoshihikaku.html)を優先します。
この年表は政令指定都市・東京都区部の比較用資料ですが、表ごとに調査時点が異なり得ます。巻の年をすべての観測年として扱いません。
東京都全体や区市町村の補足は[東京都統計年鑑](https://www.toukei.metro.tokyo.lg.jp/tnenkan/tn-index.htm)から確認します。

### 比較を成立させる条件

- 市、都道府県、特別区、都市圏の単位を区別します。横浜市と東京都全体の規模差だけで優劣を付けません。
- 金額は総額と1人当たり等を併記し、年度、価格基準、対象範囲、分母を明示します。
- 都と市の予算・税収は行政サービスと権限の範囲が異なるため、範囲をそろえられない指標は比較不可または参考値にします。
- 人口増加、所得、住宅費、雇用、生産性、環境負荷を分けます。人口増だけを成長や政策の成功と呼びません。
- 「0」「不詳」「非公表」「該当なし」を別に保持し、丸め差と統計改定を扱います。
- 国際比較では行政区域と通勤圏を混ぜません。[OECDの都市・機能的都市圏の定義](https://www.oecd.org/en/data/datasets/oecd-definition-of-cities-and-functional-urban-areas.html)を候補にします。東京と横浜を含む範囲の重複はデータの境界情報で確認します。

## 選挙時にも検証できる公共的論点

メディアが将来扱うかは予測です。「実際に質問・報道された論点」と「構想から推定した論点候補」を分けます。
下表の質問記録はその論点が問われた根拠であり、質問文や回答に含まれる数値・批判・効果を事実認定したものではありません。

| 優先候補 | 市民が確かめられるようにする問い | 今回確認した入口・位置付け |
|---|---|---|
| 学校給食・子育て | 給食方式、費用、供給、安全、家庭負担をどう評価するか | [2025-06-11記者会見](https://www.city.yokohama.lg.jp/mayor/kishakaiken/kaikenyoshi/2025/20250611.html)で、市長選に関連して給食方式が質問されています |
| 公共交通 | バスの費用負担と、便数・生活の足をどう両立するか | [2026-05-14記者会見](https://www.city.yokohama.lg.jp/mayor/kishakaiken/kaikenyoshi/2026/20260514.html)で運賃の説明と質問があります |
| 大型事業・園芸博 | 開催・関連整備の負担、来場見込み、開催後の利用をどう検証するか | [2025-12-17記者会見](https://www.city.yokohama.lg.jp/mayor/kishakaiken/kaikenyoshi/2025/20251217.html)でチケット価格や販売促進が質問されています。総事業費・効果は別資料で確認します |
| 大都市制度 | 特別市構想でサービス、権限、負担、周辺自治体への影響はどう変わるか | [2026-05-14記者会見](https://www.city.yokohama.lg.jp/mayor/kishakaiken/kaikenyoshi/2026/20260514.html)で制度と県・他市町村との議論が質問されています。各主体の一次資料を併記します |
| 生活費・住居 | 物価、家賃、可処分所得、支援の対象と実績をどう捉えるか | 構想上の候補。住宅・所得統計と事業資料の接続が必要です |
| 成長・東京との関係 | 横浜で働ける仕事、企業立地、若年層の移動はどう変わっているか | 構想上の候補。国内都市比較と接続します |
| 高齢化・地域差 | 郊外の高齢化、医療・介護・交通へのアクセスはどう違うか | 構想上の候補。年齢構成と地域データから着手します |
| 財政・将来負担 | 現在のサービスと公共施設更新をどう維持するか | 構想上の候補。予算、決算、債務、基金、施設更新計画をそろえます |

最初は「給食・子育て」「公共交通」「大型事業」の3件を、検証対象を絞った論点ページにする案です。
特別市や成長・雇用は、制度説明と都市比較が整い次第追加します。これは報道量の順位や将来の選挙争点の確定ではありません。

### 論点ページの型

1. 何が問われているかと、掲載する根拠の基準日。
2. 確認できた事実、時系列、対象地域、原典の該当箇所。
3. 市の説明、異なる立場の説明、その根拠と反証。
4. 政策の選択肢、費用、便益、制約、比較できる他都市。
5. 分からないこと、検証待ちの主張、訂正・更新履歴。

発言の事実と、発言内容の正しさを分けます。「公約として述べた」「予算化した」「実施した」「成果が出た」も別の状態として記録します。
論点を目立つ見出しだけで増やさず、資料・計算・留保を伴うページを作ります。

## 海外の都市成長・再生事例

海外の取り組みを最初から「成功事例」と決めません。構想の候補都市から、横浜と比較する問いが具体的で、資料の入口を確認できた3件を選びます。

| 初回候補 | 事例と資料 | 横浜との比較案 | 検証が必要な点 |
|---|---|---|---|
| ハンブルク | [HafenCityのマスタープラン](https://hafencity.de/en/overview/masterplan) | ウォーターフロント再開発を、みなとみらいの住宅・雇用・公共空間と比較 | 計画値と実績、地区と市全体、住宅費、公的負担、整備期間 |
| ロッテルダム | [港湾局の年次報告](https://www.portofrotterdam.com/en/about-port-authority/finance/annual-reports) | 港湾の産業転換・投資を横浜港と比較 | 港湾局の収支と都市経済を区別。市内雇用、排出、投資の実績は各資料で確認 |
| シンガポール | [JTCの土地利用・既存建物活用](https://www.jtc.gov.sg/about-jtc/news-and-stories/feature-stories/master-planning-and-adaptive-reuse) | 産業用地、研究開発拠点、既存施設再利用を横浜の産業立地と比較 | 都市国家と自治体の権限差、土地制度、財源、計画と実績 |

釜山、バルセロナは構想にあった次の調査候補として残します。今回の3件より高い成果が見込めると判定したわけではありません。
国際比較の共通項は、実施前の課題、介入内容、実施期間、費用と財源、成果指標、失敗・副作用、横浜へ適用できる条件です。
事業主体の公式説明は計画・公表値の根拠として使い、成功の独立した評価とは分けます。実績統計、監査、研究等で追加確認します。

## 開発順への反映案

1. 文章の根拠検証を公開ビルドへ接続する最小単位を先行します。[現状と強化案](FACT-CHECK.md)を参照してください。
2. 既定の人口・年齢構成の拡充と合わせ、国内比較に使う地域・定義・時点を整備します。
3. 国内比較の初回ページと、資料がそろった公共的論点の初回ページを公開候補にします。
4. 予算・決算の拡充を続けながら、海外3事例を同じ比較テンプレートで調べます。
5. 長期時系列、暮らしの分野、政策・事業・成果の接続を広げます。

都市や論点の最終的な掲載順は、資料を取得して比較可能性を確認した段階で調整します。
この提案では有料AIの契約、モデルの選定、外部への連絡、コンテンツの本番公開は行っていません。
