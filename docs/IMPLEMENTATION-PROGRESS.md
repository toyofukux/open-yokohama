## 数字の扱いで決めたこと

- 社会増減は、市外転入−転出＋市内転入−転出＋その他増減です。市内転入と転出が一致しない原典の値も、そのまま保持しています。
- 2025年の市の人口動態は自然増減−18,732人、社会増減＋18,896人、計＋164人です。政策効果の推定ではありません。
- 年齢別人口は1月1日の推計で、住民基本台帳の3月末・9月末とは別です。年齢不詳を3区分へ配分しません。
- 画面の年齢割合は不詳を含む総人口が分母です。2025-01-01の市の年齢不詳は98,789人で、無視できるゼロとして処理しません。
- 集計前の各歳・男女計を検査し、集計に使った全行番号を保存しています。別途、同じ1月1日の既存人口残高との一致も確認しました。
- 原典・定義の確認先：[横浜市統計書 第2章](https://www.city.yokohama.lg.jp/city-info/yokohamashi/tokei-chosa/portal/tokeisho/02.html)、[年齢別人口の説明](https://www.city.yokohama.lg.jp/city-info/yokohamashi/tokei-chosa/portal/jinko/nenrei/)。原本と取得記録はGit内に保持しています。
