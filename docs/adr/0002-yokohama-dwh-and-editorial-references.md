# ADR 0002: 横浜の共通データ基盤を中核にし、記事を参照で接続する

状態: 設計方針として採用、2026-09-07。実装は未着手です。
依頼は横浜市DWHへの目的拡張、数字・ファクト管理の整理、記事から参照できる目標の設定です。

## 背景

3系列・24指標・16,072値を、不変原本から検査してWeb・MCPへ配布しています。
一方で、系列別の契約、文章根拠の別台帳、記事の参照版固定と更新影響の追跡不足があります。
[現状監査](../DWH-AUDIT.md) と [目標設計](../DWH-DESIGN.md) に根拠と受入条件をまとめました。

## 決定

1. このプロジェクトの中核を横浜市域の公開データ・ファクト・出典・履歴の共通基盤とし、open.yokohamaを主要な利用媒体にします。
2. 資料・定義・地理・時間の共通台帳を持ち、観測の論理キーと不変の版IDを分けます。数値と文書ファクトは区別します。
3. 記事はデータrelease・入力値・計算・引用を参照し、公開版を固定します。更新型画面はビルドごとに公開releaseを選びます。
4. 原本→正規化正本→公開用データ→記事の依存関係を保持し、改定から影響記事を逆引きします。
5. 既存のJSON・原本・公開インターフェースを互換adapterで段階移行します。最初に人口データと記事1件で再現・訂正の経路を実証します。
6. 同日の追加指示によりMCPの外部公開を停止し、ローカル参照だけを利用します。APIキー・クラウド認証の存在を再公開の許可にしません。再開はユーザーの明示的な指示まで保留します。

## 代償と見直し

台帳・旧版・依存関係の管理が増えます。指標を追加する前に共通化へ作業を配分します。
記事版の固定により、最新値への置換は明示的な記事更新になります。表示時点と訂正状態の案内が必要です。
全文原本の保全は公開配布とは分け、資料ごとの利用条件と復元可能性を確かめます。

[ADR 0001](0001-static-public-data-core.md) の低費用・静的配信の方針は継続します。
正規化正本と公開JSONの分離を追加し、初期の公開JSONが正本を兼ねる構成から段階的に移します。
具体的なDB・外部保管・課金サービスは選定していません。容量・更新競合・再構築時間・集計需要を測って別途判断します。

## 今回の到達点

監査と設計文書、既存計画への接続までです。
DWHの実装・データ移行・新API・記事の再公開を、このADRの作成によって完了と扱いません。
