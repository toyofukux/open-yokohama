# 市民向け記事のグラフ選択ルール

更新：2026-09-10。対象はOpen Yokohamaの記事制作・レビューです。AIは構成を決める時点でこのルールを適用し、採否と理由を記事の既存レビュー記録へ残します。自動判定プログラムや公開ゲートへの実装は、今回の範囲に含みません。

## 最初に読む要点

- **区ごとの1指標の違いやレベル分けには地図を優先します。** 同じ指標・時点・区分基準を使い、人数か割合かを明示します。これはユーザーが指定した本サイトの方針です。その他の形式は記事に組み込んだ状態で都度判断します。
- 数量の大小・変化・構成が節の主張を支える場合、グラフを第一候補にします。単に数字が登場するという理由では採用しません。
- 複数指標は扱えます。何を比較するか、同じ目盛りを使えるか、足し合わせられるかを先に決め、色はその区別を助けるために使います。
- 誤解を防ぐために必要な指標は一緒に見せます。同じ単位・少数の指標で1つの問いを扱うなら、共通の座標内の並列棒を先に試します。人数と割合など、単位が異なる場合は別の図を隣接させます。
- 図を入れたら、同じ増減を繰り返す本文を整理します。図だけでは説明できない背景・意味・留保を本文に残します。

英国統計局（ONS）は伝える内容に合わせた比較と単純な図を勧め、EUの公開データガイドは絶対数と相対値で見える姿が変わることを示しています。この文書はそれを本サイトの編集工程へ具体化したものです。[ONSの選択指針](https://service-manual.ons.gov.uk/data-visualisation/chart-types/choosing-a-chart-type)、[EUのデータ変換指針](https://data.europa.eu/apps/data-visualisation-guide/data-transformation)

## 1. AIが採否を決める手順

次の順に確認します。点数の合計や文章の長さだけで機械的に決めません。

| 順序 | AIが確認すること | 判断・成果物 |
| --- | --- | --- |
| 1 | 読者は何を比べる必要があるか | 「子ども数と申込数は同じ方向に変わったか」のように、読者の問いを1文にします |
| 2 | 数量の関係が答えの根拠か | 大小・変化・内訳・分布・関連ならグラフ候補。制度や選択肢の違いなら図解・表・文章を候補にします |
| 3 | 正確な値だけを調べたいのか、関係を見たいのか | 1つの数と短い説明で足りれば文章、値の検索なら表。複数の値を頭の中で比較・計算させるならグラフを優先します |
| 4 | 比較条件と根拠がそろっているか | 時点・期間・地域・対象・定義・単位・実績/計画・原典の箇所を照合。不一致が主張を壊す場合は作図を保留します |
| 5 | 1指標だけで誤解しないか | 規模と割合、総額と1人当たり、全体と内訳などを点検し、判断に必要な補助指標を選びます |
| 6 | 指標同士はどのような関係か | 独立／部分と全体／重複／分子と分母／異単位／定義変更を記録し、下の形式表で選びます |
| 7 | 図を一目見て持ち帰ってほしい事実は何か | 1図につき中心の問いを1つにします。指標は複数でも構いません。異なる問いは図を分けます |
| 8 | 図が本文の負担を減らしたか | 挿入位置・短縮する説明・残す留保を指定。表をグラフへ移すだけで段落が増える場合は再設計します |

最低限、各数値の原典を確認してから形式を確定します。AIの記憶から値を補ったり、PDFの棒の長さを正確な人数として転記したりしません。原図しかない場合は読取誤差を明示できるか検討し、正確な比較が必要なら元表の取得を待ちます。

この手順は、メッセージを決めてから表・棒・線を選ぶ英国政府の指針を、本サイト向けに手順化したものです。[Government Analysis Function](https://analysisfunction.civilservice.gov.uk/support/communicating-analysis/introduction-to-data-visualisation-e-learning/data-visualisation-e-learning-module-2-choosing-the-right-data-visualisation/)

## 2. 問いとグラフ形式の対応

| 読者の問い・データの条件 | 第一候補 | 必須の条件・避ける表現 |
| --- | --- | --- |
| 区ごとの1指標の違い・レベル分けを知りたい | 地図 | ユーザー指定の優先形式。指標・時点・単位・区分基準を明示し、同じ基準で全18区を表示します。実数は表や区の詳細で確認できるようにします |
| 施設などの人数・金額はどこが大きいか | 横棒グラフ | 長い名称は横書き。数量は0を基準にし、自然な順序がなければ大きさ順にします |
| 少数の指標を、同じ区・同じ年で比べたい | 共通座標の集合棒（並列棒） | 同じ単位・比較可能な定義・共通目盛り。年や短い分類は縦棒、長い名称や多数の分類は横棒を先に試します。色・凡例・直接ラベルで系列を識別します |
| 2時点で何がどれだけ変わったか | 2本の棒、または2点を結ぶ図 | 始点・終点・差を表示。中間の動きを確認していなければ、毎年一貫した変化として描きません |
| 年ごとの推移や転換点を読みたい | 折れ線 | 各時点の確認済みデータと等間隔の時間軸。欠測や定義変更をつなぎません。年別支出など期間内の量なら縦棒も候補です |
| 規模の違う指標の増減率を比べたい | 増減率の棒／基準年=100の折れ線 | 前者は増減率0、後者は基準100を明示。基準年・式・元の実数も併記します。2時点しかなければ増減率の棒を優先します |
| 総数と、その構成を知りたい | 積み上げ棒 | 区分が重複せず、同じ時点・単位で合計が全体と一致するときだけ使います |
| 構成比の違いを比べたい | 100％積み上げ棒 | 各棒の分母Nを表示。総数の差が重要なら実数も見せます。途中の区分の小さな差を比べるなら並列棒へ戻します |
| 人数と割合の両方で区の違いを知りたい | 主に伝える1指標の地図＋人数・割合の表や区詳細 | 地図が示すのはどちらの指標かを明示。必要なら指標別の地図を併置します。人数最大と割合最大が異なる可能性を説明します |
| 同じ単位でも系列が多く、重なって読めない | 同型の小さな図を並べる（分割表示） | 同じ単位の大きさ比較は同じ範囲・目盛り。単位の異なる2図では別軸を明示し、棒の長さを図間で比べさせません |
| 目標・市平均と実績の差はどれだけか | 棒＋基準線、または点と基準線 | 目標は実績と区別します。差だけを示す場合にも元の実数を添えます |
| 総数から何を除くと公表値になるか | 引き算の関係図。必要ならウォーターフォール | 同じ母集団の重複しない増減で計算が閉じる場合のみ。制度上の区分なら、式と短い説明の方が伝わるか先に試します |
| 平均値が実態を隠していないか | ヒストグラム／点を並べた分布図 | 区間幅・対象数・中央値等を示します。平均だけから「典型的な人」を決めません。箱ひげ図には読み方の説明が必要です |
| 2つの指標は関連しているか | 散布図 | 各点の対象・期間をそろえ、関連を因果効果として説明しません |
| 地域がどこにあるか、近隣に偏るか | 地図 | 区別1指標は地図を優先。割合・密度なら分母、人数なら規模を示す色分けと明示し、区の面積や人口の違いを困難さと混同しません。境界値と区分の根拠を表示します |
| 制度・役割・施策の選択肢を理解したい | 関係図・比較表・文章 | 未算定の費用や効果を棒の長さに置き換えません |

並列棒の配置によって比較しやすい組が変わり、積み上げ棒の途中の区分は共通の基準線を持たないため比較しづらくなります。系列を分割する方法と折れ線の選択も含め、上表の主な根拠はONSです。[並列棒](https://service-manual.ons.gov.uk/data-visualisation/chart-types/clustered-bar-chart)、[積み上げ棒](https://service-manual.ons.gov.uk/data-visualisation/chart-types/stacked-bar-charts)、[分割表示](https://service-manual.ons.gov.uk/data-visualisation/chart-types/small-multiple-charts)、[折れ線](https://service-manual.ons.gov.uk/data-visualisation/chart-types/line-chart)

## 3. 「数字の罠」を防ぐ複数指標の組合せ

多くの指標を載せること自体を目的にしません。「これを省くと読者の結論が変わり得るか」を判断します。率や1人当たりへの変換は、比較の問いに合う分母を選ぶ必要があります。[EUの正規化の解説](https://data.europa.eu/apps/data-visualisation-guide/normalising-data)

| 誤読の起点 | 一緒に示すもの | 表現と確認 |
| --- | --- | --- |
| 人数が多い地域ほど困りやすい | 人数・該当する対象者数・割合 | 人数と割合を別図、分母をラベルか表へ。市全体の率は分子合計÷分母合計で計算します |
| 割合が上がったので該当人数も増えた | 分子・分母の実数 | 割合と実数を近くに表示。分母減少で割合だけ上がる場合を確認します |
| 62.6％増と4.9％減の人数を足し引きできる | 増減率・各指標の基準時点の人数・人数差 | 増減率を同じ軸で比べても、基準人数が違うことを図に残します |
| 部分と全体を足してよい | 包含関係と残りの区分 | 「利用児童＋保留児童＝申請者」は成立しても「申請者＋利用児童」は重複です。全体の棒へ部分を積み上げません |
| 待機0人なら未充足も0人 | 保留児童と、待機児童として数える条件 | 引き算の関係図。0を見せるための架空の棒を描かず、0人のラベルと定義を置きます |
| 市平均が改善したので全地域・全年齢が改善した | 判断に必要な地域別・年齢別の値と母数 | 分割表示や分布。全体と部分で傾向が逆になる場合もあります。該当データがなければ結論を限定します |
| 総事業費が、そのまま市の追加負担や削減可能額 | 総額・財源・既存費/追加費・初期費/継続費 | 合計の財源は積み上げ可能。純増市費や契約済み支出は別の問いとして示し、不明なら比較を保留します |
| 名目予算が増えたのでサービスも増えた | 必要に応じて物価調整値・対象人数・提供量 | 調整の基準年と方法を表示。金額だけから提供量や政策効果を推定しません |
| 施策後に改善したので施策の効果だ | 定義変更・比較対象・他の要因 | 施策時点の線だけで因果を主張しません。比較可能な対照がなければ前後の観察に限定します |

分母が0の場合、率・増減率は未定義です。欠測・秘匿・非該当は0と区別します。％の差は「ポイント」、人数の差は「人」とし、割合の変化率と混ぜません。順位や増減を政策の良否として配色しません。

標本調査の値を扱う場合は、標本数・推定の不確かさ・比較可能性を確認します。必要なら誤差範囲を付けた点の図とし、見かけの小さな差を確定的な順位・増減として強調しません。

## 4. 軸・色・ラベルの必須ルール

### 軸

- 棒は0を基準に長さを描きます。負の値があれば0から反対方向へ伸ばします。小さな差を見せるための軸省略・途中切断・3D化はしません。
- 異なる単位を左右の縦軸で重ねる二重軸は、本サイトでは採用しません。別図、または問いに合う場合だけ増減率・指数へ変換します。
- 同じ単位の図で大きさを比べる場合は、目盛り・範囲・描画領域の寸法をそろえます。スマホで別図へ分けても変えません。
- 折れ線・点の軸を0以外から始める場合は、始点を明瞭に表示し、その理由をレビュー記録へ残します。指数なら100の基準線を表示します。
- 期間・基準年・並び順の選択理由を記録します。都合のよい端点だけで傾向を作らず、長期の結論には途中の値を確認します。

0起点、比較可能な軸、二重軸回避の根拠はONSです。本サイトでは一般市民向けの読解負担を踏まえ、二重軸を「避ける」から「採用しない」へ運用上強めています。[軸と目盛り](https://service-manual.ons.gov.uk/data-visualisation/guidance/axes-and-gridlines)

### 色と読める表示

- 色は指標や区分へ固定します。同じ記事内で同じ指標の色を変えず、赤=悪化・緑=成功のような価値判断を付けません。
- 図のすぐ近くに系列名・単位・時点を直接書きます。色の凡例だけに依存せず、位置・形・線種・ラベルでも識別できるようにします。[W3C：色の使用](https://www.w3.org/WAI/WCAG22/Understanding/use-of-color.html)
- 通常サイズの文字は背景とのコントラスト4.5:1以上を目標とし、理解に必要な棒・線・境界は隣接色との3:1以上を確保します。境界線や余白で識別する場合も実画面を確認します。[W3C：非テキストのコントラスト](https://www.w3.org/WAI/WCAG22/Understanding/non-text-contrast.html)
- 文字の基準は[W3C：テキストのコントラスト](https://www.w3.org/WAI/WCAG22/Understanding/contrast-minimum.html)も参照します。
- 見出しは図から確認できる事実にします。「申込みが増えた」は可能ですが、「政策が成功した」はその図だけでは裏付けられません。
- 各図に短い要約と、全値を読めるHTML表への導線を付けます。出典・必要な母数・留保はホバーの中だけに置きません。[W3C：複雑な画像](https://www.w3.org/WAI/tutorials/images/complex/)
- 数値・棒・表は同じ確認済みデータから生成し、生成AI画像で正確な棒や数字を作りません。装飾・アニメーション・切替操作は理解に必要な場合だけ追加します。

初期値は1図2〜3指標、4指標以上なら分割を優先します。これは本サイトの編集上の初期値で、科学的な限界値やWCAGの要件ではありません。ONSの並列棒の目安は1組最大5本ですが、スマホで読めることを優先して厳しく始めます。[ONS：並列棒の系列数](https://service-manual.ons.gov.uk/data-visualisation/chart-types/clustered-bar-chart)

## 5. 保育記事へ適用した判断

対象は「子どもが減っても、保育への申込みは増えていた」の最初の段落です。原資料の表1は2004年4月1日と2012年4月1日の比較です。PDFのテキスト抽出では数字が文字化けしていたため、2026-09-10に再取得したPDF1ページ（冊子11ページ）の画像で4値を照合しました。[横浜市・調査季報172号、表1](https://www.city.yokohama.lg.jp/city-info/seisaku/torikumi/shien/tyousakihou/kihou-archive/172.files/0007_20191119.pdf#page=1)

| 指標 | 2004年4月1日 | 2012年4月1日 | 人数差 | 2004年比 |
| --- | ---: | ---: | ---: | ---: |
| 就学前児童数 | 201,626人 | 191,770人 | −9,856人 | −4.9％ |
| 保育所入所申込数 | 28,112人 | 45,707人 | ＋17,595人 | ＋62.6％ |

差=2012年値−2004年値、増減率=差÷2004年値×100。元の整数から計算し、表示時だけ小数第1位へ丸めます。この表の率は申込割合ではなく、それぞれの指標の増減率です。

### 推奨する図

**1つの座標内に、年ごとの2指標を並べた縦棒を置きます。** 横軸は2004年・2012年、縦軸は共通の0〜25万人です。就学前児童数は青、保育所入所申込数は橙に固定し、棒の上に実数、下に短い指標名、図の下に増減率を付けます。

ユーザーが示した[深津氏の記事の「年間学習費総額の公私比較」](https://fladdict.github.io/japan-todo/issues/population/low-birthrate/)を2026-09-10に実画面とHTMLで確認しました。学校段階ごとの公立・私立を1つの共通座標へ並べた縦棒で、凡例・原データ表・出典が近くにあります。本件ではその構造を、年ごとの子ども数・申込数へ対応させます。参考図の数値やコードを転載するものではありません。

初案は指標別に上下へ分割しましたが、2指標・2時点では図を往復する負担と縦の長さが増えました。今回の見本v2では4本を一緒に見られる構成を優先します。各指標の前後差は同色の棒と増減率で確認できるようにします。子どもの減少を誇張するために軸を切りません。

共通座標でも読みにくい場合は、まず並べる組を入れ替えて比較します。指標別に2年分を組にすれば前後差を近接比較でき、年別に2指標を組にすれば各年の状況を一緒に確認できます。今回の年別配置は、ユーザーが示した参考と記事内の一覧性を踏まえた編集判断です。利用者テストによる優位性の確認ではありません。[ONS：比較したい棒をまとめる](https://service-manual.ons.gov.uk/data-visualisation/chart-types/clustered-bar-chart)

一般ルールとして、同じ単位・2〜3系列・短い分類なら「共通座標の並列棒→組の並べ替え→必要なら分割」の順で検討します。複数指標という理由だけで分割しません。単位の違い、ラベルの衝突、多数の系列など、分割する具体的な理由を記録します。

[実数で作った表示見本](content-review/visualisation/childcare-history-preview.html)はブラウザで開く単独HTMLです。公開記事への組込み前の見本で、確認用の原データ表を併設しています。初期表示で両指標を見られるようにし、切替操作を必須にしません。

代案は「2004年比」の増減率2本を共通の％軸で描き、実数を添える形式です。増減の方向を強調できますが、分母が違うことを理解する負担が増えるため、最初の見本では実数を主にします。今回確認した表だけから2005〜2011年の点を作った折れ線や、2026年までつながる系列は作りません。

### 本文の置き換え案

導入を「子どもの人数と、保育所への申込みは、同じ方向には動かなかった。」と短くし、直後へ図を置きます。図の後は「市は、申込みの増加に保育所の整備が追いつかない時期があったと振り返っている。」として政策の経緯へつなぎます。図を足して元の数値説明を全部残す構成にはしません。

図のすぐ下には「2時点の比較。途中の毎年の動きや、増減の原因はこの図だけでは分からない。」を残します。申込数は潜在需要や未申請家庭の総数ではありません。就学前児童数と申込数を足して総数を作ったり、両者の差を「保育が不要な子ども」と名付けたりしません。

次の「0人と2,532人」の節は包含・除外条件の説明なので、既存の引き算の関係図を使います。地域差の節は既存18区地図を優先します。地図では申請者に占める割合を示し、人数と割合は既存の区詳細・表でも確認できるようにします。年齢別の育休延長希望を除く集計と、区別の含む集計は混ぜません。

## 7. 受入条件と検証の分担

| 確認 | 合格の条件 | 確認する担当・方法 |
| --- | --- | --- |
| 原典・比較条件 | 全値と時点・単位・対象が一致し、不成立の比較を作らない | 制作者が原表と照合。独立レビューが必要な公開変更では別担当も確認します |
| 計算・描画 | 差・率・合計・0と欠測・目盛りが正しく、図と表が同期する | 計算と描画条件を機械検査。新しい計算・描画ロジックには必要な異常系検査を追加します |
| 編集上の意味 | 図の問い、補助指標、採否理由、本文の短縮、留保がそろう | 本文と図を通読し、原典照合とは別に確認します |
| 表示・アクセス | 320/390pxとPCでラベルが読め、色なしでも区別でき、表と出典へ到達できる | 実画面、キーボード、必要に応じて支援技術で確認します |
| 読者の理解 | 図から言えること・言えないことを誘導なしで説明できる | 人間の読者に観察課題を実施。AIレビューを代替の合格記録にしません |

保育の読解課題例は「この図から何が変わったと分かるか」「2種類の棒を足した数にはどんな意味があるか」「2008年の人数や変化の原因も分かるか」です。答えを先に教えず、誤答と迷った箇所を記録します。課題自体の予備確認と市民による理解検証は未実施です。

研究・公的指針から導いたルール、本サイトが決めた初期値、個別記事の編集判断を区別します。系列数や見本の採用は、実際の読者の誤読が確認されたら見直します。
