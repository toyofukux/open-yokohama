## 自己点検で直したこと

| 指摘 | 原稿での処置 |
|---|---|
| 財源表の総額を無償化の追加費用にできない | 総額の提示をやめ、既存負担・援助・追加費用の区別を説明。追加市費は未確定と明記 |
| S4の想定81,000人には教職員5,000人が含まれる | 81,000人を生徒数とする集計を不採用。対象人数×単価で政策費用を作らない |
| 年間食数の前提が資料で異なる | S4は170日見込み、S7の図は188回喫食した場合。統一した実績と扱わず、原稿は20食の条件付き例にした |
| 「市独自補助」から市税だけと誤解しうる | 臨時の国交付金を使う事実を、金額の説明に接続 |
| 国への提案を実施決定と誤読しうる | 提案事項「案」の位置付けを本文にも表示 |
| 一律支援と対象を絞る援助の違いが抽象的 | 現行援助の支払い不要と、審査中の立替を具体的に説明 |
| 制度資料から効果・需要を推定しうる | 非申請者の人数、家計改善の実測、代表的な市民ニーズ、出生率等への効果を断定しない |

これは同じ制作者による自己点検であり、独立レビューの代替ではない。

## 未解消事項と採用への影響

- **追加費用：** 支払対象食数と既存援助の財源対応を未確認。公式サイト内の2026年度給食費・無償化・追加財源検索、当初事業計画、委員会資料を調べた範囲で積算を確定できていない。資料が存在しないとは断定しない。費用の妥当性にまで答える記事としては未完成。
- **継続財源・最新の政策決定：** 2026年度の現行料金案内と、時点を明記した政策資料を使用。9月時点の全補正・全会議録の網羅確認は未実施。国への提案のその後も未確認。公開前に現行料金・予算・決定状況を再照合する。
- **価値と範囲：** この問いが本人の知りたいことに合うか、申請案内を求める人と政策比較を求める人の違い、保護者以外にも読む理由があるかは未検証。
- **理解：** 「無償化で全員に現金」「市補助は全額市税」「国の要請案は実施決定」「20食例は固定月額」という誤読が起きないかは未検証。AIの自己点検では解決済みとしない。
- **採用：** 原稿の大枠はユーザーが初版実装の内容として採用した。画面は一問の初版であり、利用者検証・全サイトへの構成採用は未実施。参考サイトの構成原理を参照し、本文・比較軸・数値は独自に作成・調査した。
