# 市長の権限：制作・確認記録

更新：2026-09-09。Q03の読者の問いは「市長に期待する変化を、誰の判断を経て実施するか」。給食・学校・民間バスを具体例に、二元代表制、教育委員会、予算と運営の役割を説明する。需要仮説は、約束の主体と実現条件を区別すると政策を読みやすくなること。人間の読後理解は未検証であり、法令の要約が理解を妨げるなら説明順を見直す。

## 原稿と図

- 正本：[mayor-powers.md](mayor-powers.md)。事実・法令の要約と、確認する問いの提案を分ける。具体的な条例改正・事務委任・個別の許認可判断まで確定していない。
- [原典台帳](sources.json)：市の説明2件、法令3件、地域交通の制度1件。法令はe-Gov API v2で2026-09-09を指定し、返却された施行版と本則を照合した。地方自治法は2026-09-03、地方教育行政法は2026-04-01、道路運送法は2025-06-01施行版。
- 給食・学校の具体例の後に[役割図](../../../data/editorial/figures/mayor-roles.html)を置く。新たな予算を伴う施策の一般的な説明であり、組織の上下関係や全事務の手順を示さない。
- 図は原資料の事実を基に独自にHTMLで整理したもの。[図の台帳](../../../data/editorial/figures/manifest.json)に版・範囲・作成主体を記録する。第三者の図版や写真は転載していない。

## 確認の範囲

[check.py](check.py)は原本のhash、抽出文、施行版、引用した本則条文、脚注とリンクを確認する。[checks.json](checks.json)は制作者による実行結果。附則の同じ条番号を本則と取り違えないよう、MainProvision内から抽出する。事実確認をAIの自己申告だけで完了扱いにしない。

公開契約は[publication.json](../publication.json)のmayor-powersレコード。制作・公開は「他の記事もどんどんよろしく」と従前の公開委任を根拠に進める。人間による本文の逐語レビューとは区別する。

独立レビューと表示確認は別記録にまとめる。人間の価値・操作・理解の検証は未実施。既存の選挙7論点を保ち、基礎記事として一覧・検索・選挙入口から案内する。
