# 保育記事の図の配置と本文整理

2026-09-10。「区ごとの1指標・レベル分けは地図を使う。他は記事へ組み込んで都度判断する」というユーザーの方針を適用します。形式を検討し直すための一律の事前承認は設けません。

| 節・位置 | 採用する図 | 読者が確認すること・本文整理 |
| --- | --- | --- |
| 子どもが減っても、保育への申込みは増えていた：導入の直後 | 新規・2004/2012年の共通座標の並列縦棒 | 子ども数と申込数の逆方向の変化。数の説明を図へ移し、本文は整備が追いつかなかった背景と政策の経緯へ進めます |
| 2026年の0人と2,532人は、何を数えているか | 既存・引き算の関係図 | 申請者→保留→国の定義による待機児童の違い。図の前後の人数・除外区分の重複説明を短くし、「全員が直ちに必要」「支援不要」という誤読への留保を残します |
| 1・2歳児の不足と、18区の違いを見る：最初の段落の後 | 新規・0〜5歳の保留児童数の縦棒 | 育休延長希望を除く1,256人のうち、1・2歳が904人、約72％。年齢別の保留率や必要な新設枠と読み替えません |
| 同節：地域差の説明の直後 | 既存・18区の地図 | 申請者に占める保留児童割合の段階表示。区の人数・割合・母数を確認できる既存の詳細・表を維持します。年齢図との母数差を近接表示します |
| 同じ不足に、どの受入れを増やすか | 既存・選択肢比較表 | 課題ごとの対応と負担を比較。費用・効果が同条件で未算定なので、長さや面積を持つ図へ変換しません |
| 結び | 短い本文 | 年齢・場所・時期・人員・継続費という確認条件を結びます。同じ内容の装飾図は追加しません |

2010〜2013年の待機児童減少は短い本文で扱います。歴史図・現行の定義図と役割が重なり、2013年と2026年を同一定義の系列に見せるおそれがあるため、独立のグラフを増やしません。

新規図はN4の表1とN1の2ページから作成します。入力JSON・生成関数・出力HTMLを同期させ、原典の版、人数の合計、増減率、棒の目盛り、欠測・母数の混同を検査します。出典・表・重要な留保は図の近くに置きます。図の挿入後の本文、スマホ・昼夜表示、キーボード、独立レビュー、公開契約を確認してから反映します。
