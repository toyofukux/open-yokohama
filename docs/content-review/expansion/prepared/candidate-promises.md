候補者の公約は、見出しや強調する分野が異なる。同じ問いに並べ直すと、政策の方向が違うのか、具体的な説明の量が違うのかを分けて読める。

## まず、誰の、いつの資料かをそろえる

2026年9月9日に確認した横浜市長選の公式ページでは、候補者情報と選挙公報は今後掲載予定となっている。この稿は比較の準備で、今回の候補者一覧や公約を確認済みとは扱わない。[^1]

資料が公表されたら、候補者本人の公式資料と選挙公報を記録し、発表日・更新日・確認日を区別する。以前の選挙の公約や、報道された発言を、今回の最終的な公約へ無条件に置き換えない。

## 生活上の問いを、同じ項目で読む

| 比較する項目 | 確かめる問い |
| --- | --- |
| 目的 | どんな困りごとを減らすのか |
| 対象・手段 | 誰に、何を、どの条件で行うのか |
| 期限・規模 | いつまでに、どこまで進めるのか |
| 費用・財源 | 総額と追加市費は何年度の数字か |
| 実行手順 | 市会や関係機関と、何を調整するのか |
| 点検方法 | どの結果を、いつ公表するのか |

市長が予算等を提案しても、市会の議決などの役割が関わる。公約に実施の意思があることと、必要な手順を終えたことは分けて確かめたい。[^3]

## 書かれていないことを、反対と決めない

記載がない項目は「公式資料で確認できない」とし、賛成・反対を補わない。財源の説明がない場合も、その政策が無費用だと扱わない。

数値がある場合は、年度・対象・総額か追加額かをそろえる。目標と実績、本人の約束と第三者の評価も別に記録する。引用は短く範囲を明示し、要約には原資料を付ける。

## 比較を公開する条件

今回の選挙は10月4日告示、10月18日投票と案内されている。公式公報等の公表後、対象候補者を漏れなく確認し、同じ項目と資料確認日で比較する。[^2]

本文の完成には、候補者別の根拠、比較可能な政策項目、未記載・不明の明示、要約の独立照合が必要になる。現時点では準備稿として保存し、実際の候補者比較を公開済みにはしない。
