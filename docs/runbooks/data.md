# データを更新する

ルートで `pnpm data:refresh` を実行してください。
元サイトのCSV一覧から2024年以降を取得。サイズ・タイムアウト・取得先を制限します。
生CSVはSHA-256名で追記し、同名の内容が異なれば停止します。取得・解析失敗で掲載済みJSONを変更しません。

- 同一原本は同一取得記録を保ち、JSONを書き換えません。
- 新しい時点は、数値検査後にローカルの公開JSONへ追加します。Web公開は別途ビルド・デプロイします。
- 過去の値が変わった場合は `artifacts/population-candidate.json` と差分を出して停止します。
- 形式変更・参照切れ・欠測は `artifacts/ingestion-failure.json` に記録します。

過去値の訂正を採用する際は、原本と変更理由を確認し、対象値と出典のハッシュをレビュー記録に残します。
確認後に候補JSONを `data/published/population.json` へ移し、`pnpm verify` を実行してPRで履歴を残します。
以前の `data/raw/` と `data/manifests/` は削除しません。

週次GitHub Actionsは検査のみを実行します。更新候補や取得失敗はジョブ失敗で可視化し、成果物を30日保存します。
Actions失敗通知はリポジトリ管理者がGitHubで受け取ります。独自メール・Slack送信は未設定です。
新データが出ても自動公開しません。管理者が差分を確認して取り込み、Webをデプロイします。MCPは公開停止中のためローカルで同じデータを検証します。

人口・世帯等は32か月・9指標です。別系列として人口動態10指標と年齢構成5指標も収録しています。期間・地域範囲は下記の各節を参照してください。
予算・政策・国内都市比較は未収録です。系列を横断する管理の現状は[監査](../DWH-AUDIT.md)、今後の共通化は[DWH設計](../DWH-DESIGN.md)を参照してください。
文章の実公開ゲートは `packages/factcheck/` と `scripts/factcheck.ts` にあります。記事・根拠を更新すると旧検証は失効します。`pnpm factcheck:review` による再検証は編集時だけ明示的に実行します。
AI検証の主張ID・引用ID・本文ハッシュを照合する契約テストを提供しています。現在の数値公開は原典の直接検査を使います。

文章レビューと数値照合の違い、実行方法、検証範囲は[ファクトチェックの実装状態](../FACT-CHECK.md)を参照してください。

## 人口動態（出生・死亡・転出入）

`pnpm data:refresh:dynamics` は表8の市月別・市年別・区年別CSVを取得します。
初版は市月別2000-01〜2026-07、市と18区の暦年2000〜2025、10指標・8,130件です。
区別の月次内訳、年齢構成、人口残高の長期延長はこの系列に含めません。

- 原本は `data/raw/<sha256>.csv`、取得記録は `data/manifests/`、掲載候補は `data/published/dynamics.json` に置きます。
- 同じ原本の再取得は `unchanged`。取得日やデータ作成日を更新しません。
- 数字の改定または既存期間の削除は `artifacts/dynamics-candidate.json` と `artifacts/dynamics-ingestion-report.json` を出して停止し、掲載JSONを保持します。
- 取得・形式の失敗は `artifacts/dynamics-ingestion-failure.json`。過去値の変更理由・新旧原本・差分を確認してから候補を採用します。
- `pnpm data:validate` は両系列の原本ハッシュ・再解析結果を照合します。`pnpm test:dynamics-gates` は一時ディレクトリで原本改変と年全体の削除を拒否することを検査します。
- 男女計、出生−死亡、自然＋社会、市外転入−転出＋市内転入−転出＋その他、市区合計、12か月と年計を照合します。
- 市内移動の転入と転出の差は、原典どおり残します。社会増減を市外の転入超過だけに置換しません。
- 暦年は1月〜12月、月はその月の届出による増減です。月次人口残高の前月届出増減とは1か月ずらして照合します。
- 表8の注記原本（Excel）は `data/references/dynamics-notes.json` と対応する不変原本に保持します。新しい年の採用時は公式の注記変更も確認してください。

週次更新検査は人口・人口動態・年齢構成の3系列を対象とします。新しい候補は自動公開しません。公開対象はWebで、MCPの公開停止を維持します。
新規ページの数値は決定的な原本照合、定義・表示は実装レビューの対象です。既存3記事のAI検証を新規ページ全体の検証済み表示へ流用しません。

## 年齢構成

`pnpm data:refresh:ages` は表5の各歳・男女別CSV（初版約6.2 MB）を取得します。10 MB・30秒を上限とし、リダイレクトを拒否します。
`data/published/ages.json` は2000〜2025年の各年1月1日、19地域×26年＝494レコードに5指標を保持します。
各歳0〜99歳、100歳以上、年齢不詳、総数と男女を検査したうえで、0〜14歳／15〜64歳／65歳以上へ集計します。

- 年齢不詳は独立した値です。3区分へ配分せず、表示割合の分母に含めます。
- 集計根拠は単独の行ではなく `sourceRows` に保持します。JSON、CSV、MCPでも全入力行を参照できます。
- 更新候補・差分・失敗は `artifacts/ages-candidate.json`、`ages-ingestion-report.json`、`ages-ingestion-failure.json` です。過去値変更・削除で掲載JSONを保持します。
- `pnpm test:ages-gates` は原本改変、出典行の偽装、年全体の削除を実公開検査で拒否するか検証します。
- 年齢構成は毎年1月1日の推計です。月次推計人口の最新時点や、住民基本台帳の3月末・9月末と時点・定義を混ぜません。
- 既存人口の同じ1月1日の総数と一致することも単体テストで照合しています。新資料で不一致が出た場合、基準改定や公表版の差を確認してください。
