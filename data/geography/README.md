# 横浜18区の共通地図

`yokohama-wards.json` は国土数値情報の行政区域（N03、2023年1月1日、神奈川県）を加工した描画座標です。最新年と称さず、統計の年とは別に表示します。

- 原資料・作成者：国土交通省 [行政区域データ](https://nlftp.mlit.go.jp/ksj/gml/datalist/KsjTmplt-N03-v3_1.html)
- 固定原本：[N03-20230101_14_GML.zip](https://nlftp.mlit.go.jp/ksj/gml/data/N03/N03-2023/N03-20230101_14_GML.zip)
- [利用条件](https://nlftp.mlit.go.jp/ksj/other/agreement.html)：公共データ利用規約1.0。利用時は出典と加工した旨を記載してください。コードのMITライセンスとは別です。
- ZIPの取得記録・ハッシュはJSON内のarchiveに記録。原本は非公開のartifactsに保持します。
- 生成：`scripts/prepare-ward-base.py`。横浜市の55ポリゴンを18区へ統合し、局所座標へ投影、0.3描画単位で簡略化。緯度経度や測量機能は公開しません。
- 表示：`packages/core/ward-map.ts` の `renderWardMap(base, values, title, description, colors?)`。6桁区コード、表示値、分類、任意の色を入力し、SVGを返します。欠損は斜線で、0と区別します。
- 区名位置は最大ポリゴンの重心に基づき、中央部の4区を読みやすさのため調整しています。境界線を動かす調整ではありません。
- 白地図：`apps/web/public/maps/yokohama-wards-base.svg`。政策データごとの塗り分けにはJSONと上記関数を再利用してください。

## 数字から画面まで

1. 同一定義・同一年の一次資料を取得し、ハッシュ・対象・表の位置を固定します。
2. 抽出表を保存し、全18区・市合計・分母を検算します。意味と原資料の表を制作者が照合します。
3. 人数か割合か、参照値、色の閾値、何を意味しないかを記事ごとに決めます。
4. 同じ導出データから、凡例・ラベル付き地図、比較表、CSVを生成します。
5. 出典・対象日・分類条件を載せたSVGと、固定フォントでPNGを書き出します。
6. 原稿と図表の版を公開契約に結び、表示・操作を確認して公開します。理解の検証と全サイトへの採用は別に判断します。

保育の実例は `pnpm maps:build`。`pnpm maps:check` はネット接続せず全出力を再計算し、バイト単位で比較します。通常の `pnpm build` に組み込み済みです。
別記事への適用時は、保育の比較基準を無条件に流用せず、分母・時点・地域単位と参照値を先にレビューしてください。
